# Maajabu Restaurant Website

A website for Maajabu Restaurant in Luanshya, Zambia. Customers can browse the full menu, build an order in a cart, and send it to the restaurant on WhatsApp.

## Features

- **Menu:** dishes grouped into ten categories, including starters, grills, traditional dishes, chicken, fish, beef, sides, beverages, desserts and specials
- **Cart and ordering:** add dishes to a cart, see the subtotal and total, and send the order through WhatsApp
- **Pages:** Home, Menu, About and Contact
- **Responsive layout:** works on phones, tablets and desktops

## Tech stack

- React and TypeScript
- Vite
- Tailwind CSS with shadcn/ui components
- Vitest for tests

## Run it locally

You need Node.js installed.

```bash
git clone https://github.com/Mboma888/maajabu-delightful-dining.git
cd maajabu-delightful-dining
npm install
npm run dev
```

Then open the local address shown in the terminal.

## Project structure

```
src/
  components/   Navbar, Hero, MenuCard, Cart and other building blocks
  contexts/     Cart state
  data/         Menu items
  pages/        Home, Menu, About, Contact
```
